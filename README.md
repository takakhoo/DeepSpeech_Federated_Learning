# Archived DeepSpeech reconstruction snapshot

This repository is an early, incomplete copy of the long-audio DeepSpeech gradient-reconstruction work. Its original README described files and artifacts that were not present in the published repository, so it should not be used as a reproducible implementation.

The maintained public artifact is:

## [federated-asr-gradient-inversion](https://github.com/takakhoo/federated-asr-gradient-inversion)

That repository contains the runnable experiment entry point, DeepSpeech dependency snapshot, selected ten-second reconstruction artifacts, portable dependency guidance, and explicit reproduction limits.

This repository is retained only to preserve old links and research history. It is archived and receives no updates.
